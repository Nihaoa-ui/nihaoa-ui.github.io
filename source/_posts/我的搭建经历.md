今天花了一个多小时，从零搭好了自己的博客。记录一下全过程，也给以后留个备忘。

## 一、准备环境

| 工具 | 说明 |
| --- | --- |
| Node.js | 电脑本来就有（v24） |
| npm | 本来就有 |
| Git | 没有，用 winget 装的 |

顺便做了两件事：

-   配置 Git 身份（用户名、邮箱）
-   把 npm 源切到国内镜像，安装速度飞快

## 二、搭建博客

用的是 **Hexo**（一个静态博客框架）。

```bash
npm install -g hexo-cli   # 安装脚手架
hexo init blog            # 初始化博客
```

然后在配置里改了站点名、作者、语言、网址，并装上了 **Fluid 主题**：

```bash
npm install hexo-theme-fluid
```

## 三、本地预览

```bash
hexo generate   # 生成网页
hexo server     # 本地预览
```

浏览器打开 `localhost:4000` 就能看到博客。

## 四、部署到 GitHub Pages

1.  装部署插件 `hexo-deployer-git`
2.  建一个叫 `用户名.github.io` 的仓库
3.  配置部署信息，然后：

```bash
hexo clean
hexo generate
hexo deploy
```

## 五、写文章

```bash
hexo new "文章标题"    # 新建文章
```

写完后，同样的”三连”发布：

```bash
hexo clean
hexo generate
hexo deploy
```

## 踩过的坑

1.  **PowerShell 禁止运行脚本** → `Set-ExecutionPolicy RemoteSigned`
2.  **GitHub 连不上**（网络时好时坏）→ 多试几次，或者搞个梯子
3.  **主题没装上**（GitHub 断了）→ 改用 npm 装主题

## 总结

写博客本身就是练技术：Git、Markdown、部署、配置，全都用上了。这也是我”数学 + 计算机”方向的一个小起步。
